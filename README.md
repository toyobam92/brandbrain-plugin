# Brand Brain for Claude Code

One command, `/brandbrain <words>`, for your brand's videos, music, captions and calendar. Works with your [Brand Brain](https://brain.fowl-ai.com) account (7-day free trial, then $29 a month).

## Install

In Claude Code:

```
/plugin marketplace add toyobam92/brandbrain-plugin
/plugin install brandbrain@fowl-ai
```

Then run `/mcp` once and sign in to Brand Brain.

## Try it

```
/brandbrain help
/brandbrain effects bold-pop
/brandbrain fx checklist
/brandbrain music upbeat
/brandbrain sfx whoosh at 1.5
/brandbrain schedule friday 7pm
```

Nothing is ever posted without your yes. More: https://brain.fowl-ai.com/developers
